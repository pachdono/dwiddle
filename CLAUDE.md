# Notes for Claude sessions on Dwiddle

## Videos and slideshows

Anything made as a video, slideshow or carousel (Instagram posts, explainers, demos) goes in
the owner's `dwiddle-videos` folder on their Mac, one numbered folder per piece, continuing
from the last number. The folder names so far run `01-pov-28-pages`, `02-free-vs-paid`,
`03-ask-the-duck`, `04-yes-this-app-is-free`, `05-stop-rereading`, `06-exam-reaction`.
The next one is `07-<short-name>`.

Sessions run in the cloud and cannot write to that Mac, so deliver each piece as a zip
containing the numbered folder (slides or video, plus `caption.txt` for posts), and say which
number it is. Keep the numbering going: if unsure of the latest number, ask.

## House style

British English, no em or en dashes, no emoji or sparkle icons. Short, casual replies.
Commits are authored as Pacharapol Maleenont with no Claude trailer. Push to `main` and to the
session branch.
